---
title: Secrets
description: Standard env vars, scoped project → branch → service.
---

Apps need no insta-specific code. Credentials arrive as standard `DATABASE_URL` / `AWS_*` variables, injected at deploy time.

```bash
insta secrets --print                                # full bundle (gated)
insta secrets tree                                   # names-only project → branch → service binding tree
insta secrets set NAME=value [--branch] [--service]  # project-wide, branch override, or service-bound
```

Reserved names are rejected. Writes are gated by `secrets.write`.
