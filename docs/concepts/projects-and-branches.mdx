---
title: Projects and branches
description: A branch is a whole environment, cloned.
---

A **project** provisions real resources: a Postgres database, an S3-compatible bucket, and your app containers.

A **branch** is a disposable, fully isolated clone of all three. `insta branch create` copies the database (with data), copies the bucket, and redeploys every app container, each branch on its own URL, ready in seconds. Break it, throw it away; the source is never touched. One task, one branch, many in parallel.

`insta branch merge <source>` is structural and additive: compute groups missing on the target materialize against its own db and bucket; data never merges.
